# obsidian_public

Obsidian 形式のノートを普通の Web ページとして公開するためのリポジトリです。

## できること

- Markdown ノートの一覧表示
- ノート本文の表示
- Obsidian の `[[wikilink]]` を普通のリンクとして表示
- GitHub Pages での公開
- ノートファイルを自動収集して表示
- ファイル名が `.` で始まるものは下書きとして非表示

## 使い方

1. `notes/` に Markdown ファイルを追加する
2. 下書きはファイル名を `.` 始まりにする
3. GitHub Pages を有効にして公開する

## 動作環境

- GitHub Pages
- 近年のブラウザ

## ノートの書き方

- 通常の Markdown を使う
- 見出し、箇条書き、引用、コードブロックに対応
- ノート間リンクは `[[ノート名]]` 形式で記述する

## 公開のポイント

- 公開したいノートは `notes/` に `.md` で置く
- 非公開の下書きは `notes/.draft.md` のように `.` 始まりにする
- 画像を置く場合は、同じリポジトリ内の静的ファイルとして管理する
