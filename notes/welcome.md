# Welcome

このサイトは、Obsidian で書いたノートをそのまま Web に載せるための公開ページです。

## 使い方

- 左の一覧からノートを開く
- `[[Publishing Notes]]` のようにノート間をつなぐ
- 公開したくない内容は `notes/index.json` に入れない

> [!tip]
> Obsidian の書き方を大きく変えずに、そのまま公開用の Web ページにできます。

## できること

1. Markdown をそのまま表示
2. ノート一覧を表示
3. 検索で絞り込み

```text
公開したいノートを増やすだけで、公開ページも増えていきます。
```
